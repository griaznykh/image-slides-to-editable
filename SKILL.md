# Слайды-картинки → редактируемая презентация (DeckCraft)

Результат: `.pptx`/`.deckcraft`, где у каждого слайда **фон** = исходная картинка со стёртым текстом
(фон не выделяется и не сдвигается), а текст набран заново в текстовых блоках с подобранными
шрифтом, кеглем, цветом, выравниванием и интервалом.

Все скрипты лежат в `scripts/` рядом с этим файлом (`SKILL_DIR` ниже — эта папка).
Python-скрипты запускай интерпретатором `$SKILL_DIR/.venv/bin/python` с флагом `-I`.
Рабочую папку (`WORK`) создавай в scratchpad-директории сессии.

## 0. Окружение (один раз)
```bash
$SKILL_DIR/scripts/setup.sh        # venv: easyocr (CPU torch), opencv, python-pptx; ~1 ГБ, несколько минут
```
Нужны шрифты Noto Sans / Noto Serif (`fc-list | grep Noto`). Другие семейства — через `FAMILIES` в спеке.
DeckCraft должен быть запущен (MCP-инструменты `mcp__deckcraft__*`, загрузить через ToolSearch).

## 1. Извлечь картинки и посмотреть на них
```bash
PY="$SKILL_DIR/.venv/bin/python -I"
$PY $SKILL_DIR/scripts/extract.py input.pptx $WORK          # src/slideN.png + meta.json (размер слайда в pt)
$PY $SKILL_DIR/scripts/sheet.py "$WORK/src/slide{}.png" $WORK/src_sheet N
```
Посмотри листы `src_sheet*.png` (Read). `extract.py` печатает, на каких слайдах уже есть
редактируемый текст поверх картинки (`meta.json → texts`) — такой текст (например, автор
перекрыл подзаголовок белыми плашками и вписал свой) **важнее** текста на картинке:
переноси в спеку его, а белые плашки не нужны — текст под ними будет стёрт.
Если исходник — просто папка изображений, положи их как `WORK/src/slideN.png` и создай
`meta.json` вручную: `{"slide_w":1280,"slide_h":720,"slides":{"1":{"image":"…","px":[W,H],"pic_box_pt":[0,0,1280,720],"texts":[]}}}`.

## 2. OCR и стирание текста
```bash
$PY $SKILL_DIR/scripts/ocr.py $WORK                  # ~1–2 мин на 15 слайдов на CPU
$PY $SKILL_DIR/scripts/erase.py $WORK --notebooklm   # --notebooklm: стереть водяной знак в правом нижнем углу
$PY $SKILL_DIR/scripts/sheet.py "$WORK/bg/bg{}.png" $WORK/bg_sheet N
```
Проверь `bg_sheet*.png`. Типичные остатки — точки, тире, скобки рядом с краем фигуры.
Их координаты (в pt) добавь в `extra.json` (`{"7": [[x0,y0,x1,y1]], "*": [...]}`) и перезапусти
`erase.py … --extra extra.json --slides 7`. Рамки карточек и линии таблиц скрипт защищает сам.
Крупные фрагменты удобнее смотреть кропом (PIL crop → Read).

## 3. Скелет с фонами → открыть в DeckCraft
```bash
$PY $SKILL_DIR/scripts/skeleton.py $WORK $WORK/skeleton.pptx
```
`mcp__deckcraft__open_presentation {path: WORK/skeleton.pptx}`. (Команда DeckCraft
`design.background` принимает только base64 — поэтому фон ставится здесь.)

## 4. Спека текста
```bash
$PY $SKILL_DIR/scripts/dump_ocr.py $WORK            # строки OCR в pt: x0 y0 x1 y1 h conf text
```
Скопируй `examples/spec_template.py` в `WORK/spec.py` и опиши каждый слайд (полный рабочий
пример на 15 слайдов — `examples/example_spec.py`). Правила, которые дали хороший результат:
- **Текст набирай сам по картинке**, OCR — только для координат (он теряет «», —, точки, путает буквы).
  Явные опечатки оригинала (повторы слов) исправь и скажи об этом пользователю.
- Один блок = один логический кусок: заголовок слайда, подзаголовок, заголовок карточки,
  тело карточки. Заголовок и тело карточки — **разные** блоки (так не нужно частичного форматирования).
- `x0,y0` — левый-верхний угол первой строки, `x1` — правый край самой широкой строки, `y1` — низ последней.
- Тела карточек: `w` = внутренняя ширина карточки, переносы `|` без `br` (текст перетекает при правке).
  Заголовки, стихи, текст в узких кругах, центрированные 2-строчные подписи: `br=1`.
- Одинаковые элементы — в одну группу `g` (`'h'` заголовки карточек, `'b'` тела), чтобы кегль совпадал.
- Центрированные заголовки колонок/карточек: `a='center', cx=<центр карточки>`.
- Цвета: заголовки тёмно-синий/почти чёрный (`#1B2233`), тело `#26303F`; на тёмном фоне `#FFFFFF`;
  засечковые слайды (цитаты, «книжный» стиль) — `f='serif'`.

## 5. Сгенерировать и выполнить команды
```bash
$PY $SKILL_DIR/scripts/gen.py $WORK/spec.py 3          # сначала один насыщенный слайд для калибровки
```
Вывод — JSON-массив; передай его как `commands` в `mcp__deckcraft__batch`, затем
`mcp__deckcraft__render_slide {slide: 2}` и сравни с исходником. Если всё на месте — генерируй
по 3–4 слайда за вызов (`gen.py spec.py 1 2 4`) и после каждого пакета рендери (`scale: 0.6`).
Правки уже вставленного: `edit.select {ids:[…]}` + `format.paragraph` / `format.fontDialog` /
`shape.setBounds` (id берутся из результата batch или `inspect_slide`). Если блоки съезжают
по вертикали систематически — параметр `--yoff` (по умолчанию 0.33 кегля).

## 6. Сохранить и доделать фон
`mcp__deckcraft__save_presentation {path: …/name_editable.pptx}` (и при желании `.deckcraft`).
Если на готовом слайде видна «тень» стёртого текста или нужно поправить фон, не переделывая текст:
```bash
$PY $SKILL_DIR/scripts/patch_bg.py deck.pptx 1 --white 140 560 840 690   # закрасить белым (pt), с растушёвкой
$PY $SKILL_DIR/scripts/patch_bg.py deck.pptx 5 --fill 360 620 400 660    # inpaint прямоугольника
```
и переоткрой файл в DeckCraft. Сохраняй рядом с исходником под новым именем, исходник не трогай.

## Итог для пользователя
Сообщи пути к файлам, какие шрифты использованы (Noto может отсутствовать в PowerPoint на Windows —
тогда шрифт подменится), какие опечатки исправлены и где на фоне могли остаться слабые следы.
